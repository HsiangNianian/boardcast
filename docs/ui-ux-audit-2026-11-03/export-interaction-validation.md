# 启动、保存状态与导出交互验证

本批补齐 C01、C33 的保存时间、C45、C54 中尚缺的交互，并修正 C67 验证发现的键盘与短窗口问题。范围不等于全部 C01–C68 或全部发布门槛完成。

生产浏览器预览为 `http://127.0.0.1:1430`。最终入口 `assets/index-wJzP71XI.js` 及相关源码 SHA-256 见 [构建身份](evidence/implementation/export-interaction-build.json)。矩阵、工作台和内容回放使用 `index-CMyltQYG.js`；随后只把导出提示、快捷键帮助中残余的 PAD/PC 名称统一为手绘/自由编辑，并在最终入口复跑导出交互。欢迎动画的故障注入使用开发服务器的实际组件 fixture。

## 已实现的行为

- 欢迎动画使用现有原生 Dialog 隔离背景；跳过按键不会继续触发背后的快捷键。父组件反复更新不重置退出计时；字形组件不报告就绪时仍有退出上限，减少动态时直接退出。
- 原话向上滚动后保留阅读位置，并累计新定稿数量；回到最新时清零。保存状态展示确认版本的保存时间，无法解析的历史时间不会令工作台崩溃。
- 导出先选择整场会议或当前白板。前者提供 Markdown、整场 PDF、离线回放 HTML；后者提供 PNG、SVG、动态 SVG、Excalidraw。空白当前页禁用当前页格式并解释原因，其他页与原话仍可整场导出。
- 生成前固定快照；界面显示准备、生成、等待系统保存等已知阶段。进行中拒绝重复导出，包括原生菜单入口。取消系统保存没有成功提示；生成失败不会弹保存框，保存失败提供可写目录／空间检查提示与重新导出入口。
- 桌面保存成功保留路径及打开文件、显示所在文件夹、关闭入口。打开失败可重试；过期操作返回时不会覆盖新导出的提示，即使两次使用相同路径。浏览器只称文件已交给下载，不显示原生文件入口。
- Rust 新增两个受限命令，只接受本次运行中成功导出的规范路径；缺失文件、替换为其他目标的符号链接及未导出路径被拒绝。打开文件仅接受文档扩展名，路径作为独立参数交给系统启动器，没有通用 shell 接口。

## 验证中修正的问题

常驻保存提示原先挡住再次打开的导出菜单，已将操作菜单放在提示之上。范围切换改变菜单高度时重新计算位置，避免越出短窗口。

窄窗口的会议库标签曾与保存状态重叠，现允许操作行换行并保留标题最小宽度。200% 后的 640×400 窗口会被英文输入提示挤掉内容区，因此扩展现有短窗口规则：顶部、底部独立滚动，停止按钮向顶部对齐，不随输入框高度被推下去。

侧栏键盘导航曾根据旧的选中项计算方向，焦点停在另一标签时会跳错。现以实际焦点计算下一个标签。矩阵保留完整的可见性断言；另等待浏览器缩放后的响应式布局提交，最多 1.5 秒，避免只看到新 viewport 数值却测到上一帧布局。

## 验证边界与后续

受控 IPC 不证明真实系统保存对话框、默认应用或 Finder/文件管理器已打开。系统启动器成功只显示“已请求”，不会声称已看到窗口。macOS/Windows 的实际打开、原生取消和磁盘错误仍需 G2/G3。

后续 [Linux 原生 HTML 验证](native-export-validation.md) 补上实际 GTK 保存/取消、文件权限失败与直接重试，以及 Chromium/Thunar 窗口。测试只对 HTML 跑通原生交接，不把本报告七格式的浏览器/受控 IPC 结果扩张为七格式全部原生通过；字段自动化提前提交和残留覆盖框的限制单独记录。

本批不改变 ASR 策略。真实 Mac 权限、VoiceOver、签名更新、60 分钟音频会话及 G4 用户任务仍未执行。收音中新建／切换的显式确认、剩余 C01–C68 变体继续按完整方案核对。没有提交、推送或发布。
