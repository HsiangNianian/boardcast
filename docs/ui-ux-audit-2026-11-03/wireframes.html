空间分配规则

  1. 页缩略图折成页选择器，页码持续可见。
  2. 白板、原话、摘要切换主内容，避免三栏一起挤窄。
  3. 录音和停止固定在底部；保存错误占据文档流，不覆盖按钮。
  4. 较少用的动作进入“更多”，保留文字名称和快捷键。
保存失败时的行为约定

新建、切会、退出或安装更新前必须处理未保存内容。提供重试、导出救援副本、留在当前会议；明确选择放弃才可丢弃。读屏通知一次错误，焦点不被反复抢走。此处是交互规范，不代表持久化修复已完成。
