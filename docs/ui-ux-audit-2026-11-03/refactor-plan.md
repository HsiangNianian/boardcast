版本：2026-11-03 · 基线 `4f9ab26a46f07cc5575460fd7431f1a995e705cc` · 状态：**实施中，核心批次已落地，完整验收未完成**；当前进度见[实施记录](implementation-progress.md)。

本方案由独立 plan agent 在竞品研究、客户端体验审查及 #73–#78 建立之后编制。依据：[研究](research.md)、[独立锐评](critique.md)、[全部功能清单](coverage-inventory.md)、[实际执行与剩余边界](runtime-coverage.md)、[issue 去重](issue-triage.md)。[五组可浏览布局](wireframes.html)是可切换亮暗色的概念附件，不是新客户端；附件采用简化色层，surface-2、分隔线和部分状态色不是第4节token的逐项实现，正式实现以本方案为准并重新验证全部组合。优先级表示本方案发布顺序，不是 GitHub 已设置的字段。

## 1. 产品决策：安静的会议工作台，有手感的白板

产品承诺保持“说话，板书自己长出来”：让主持人/参与者在讨论中看见结构，现场纠正，之后带走可信的记录。首要任务是开会前知道能否开始，开会中知道已听到和已保存什么，会后能检查、找回和导出。论文/教学用户在同一旅程中导入材料、圈着说和追溯引用。快捷键熟练用户不必付出更多点击，第一次使用的人也不依赖记忆隐藏图标。

选择 **A 安静会议工作台为框架 + B 纸本/粉笔画布为身份 + C 紧凑收音状态为反馈**。A 单独容易平淡，B 单独容易使设置和正文难读，C 单独会变成监控台；三者职责分开。Things/Linear 提供层级参考，Raycast 提供可发现动作，Audio Hijack 提供音源反馈，CleanShot 提供产物交接，Allume/Freeform 提供材料与位置意识。来源、实际看过的官方图及未实机使用的限制见研究文档。

技术上沿用 React、Tauri、现有手绘渲染器、Excalidraw、现有会议存储与 Eval。维持 SenseVoice + dynamic review + VAD 默认；Apple SpeechAnalyzer 仍是运行时探测的 macOS 26+ 选项。此次重构不引入账户、云同步、多人协作、替代 ASR、通用插件系统或另一套 UI 框架。

## 2. 信息架构与命名

```text
应用菜单（macOS 原生菜单）
├─ 会议库：最近会议 / 搜索 / 新建 / 继续旧板
├─ 当前会议
│  ├─ 准备：名称、材料、音源、转写/板书就绪
│  ├─ 工作区：白板页 + 手绘/自由编辑 + 原话/摘要/内容列表
│  └─ 复盘：摘要、来源、回放/分支、导出
└─ 设置
   ├─ 通用与外观：语言、系统/浅/深、笔迹、快捷键
   ├─ 收音与转写：来源、设备、SenseVoice/Apple、语种/说话人
   ├─ 板书与模型：本地板书、视觉组件、下载/空间/运行状态
   ├─ 远程与隐私：地址、模型、凭据、测试、发送范围、本会仅本地
   ├─ 术语与资料：全局术语、本会术语、导入能力说明
   └─ 维护与高级：更新、诊断、纠错样本、真实技术信息
```

“PAD 板书 / PC 会议”改为“手绘 / 自由编辑”（英文 `Hand-drawn / Free edit`），表明同一会议的两种视图；初次切换提供一句能力差异说明，旧叫法只在首次迁移说明中出现。设备适配不再用模式名表达。数据尚未统一时不提前用新文案宣称完全一致。

会议库使用可见的“会议库”入口，不再只依赖标题旁小图标。标题仍可点击改名；历史列表默认最近更新，保留搜索/定位、重命名、删除确认、继续旧板。先用现有列表和搜索，不添加标签系统、收藏或工作空间层级。

准备、工作区、复盘是当前会议的任务视图，不是三种互斥数据格式。“停止收音”只停采集；“结束并复盘”执行收尾/保存后切换视图，会议以后仍可继续。没有音频持久化能力时统一使用“收音/转写”，不能把“会议回放”写成可回听原始录音。

### 2.1 主要流程

| 流程 | 明确的操作与结果 | 失败/返回 |
| --- | --- | --- |
| 首次使用 | 欢迎空态的主按钮“开始会议”，次按钮“导入材料”，文字入口“体验示例”；无需模型即可体验录制示例 | 取消准备回空态；示例不写入真实历史，退出后保留先前会议 |
| 开始现场会 | 查看音源、转写就绪、板书就绪→选择本地或已同意远程→显式开始收音 | 转写不可用时给“准备转写/先打字”；板书不可用可继续记录并显示待生成，不把整场会锁死 |
| 会中纠正 | 选中对象→改字/移动/标注/删→统一保存和撤销；圈选后下一句带目标 | 取消只清本次选择；失败保留原话、对象和重试上下文；不能再生成一次重复对象 |
| 导入资料 | 选文件→显示处理进度与目标会议→预览导入概要→新会/追加/取消→聚焦第一页 | 异步期间目标固定；取消不修改原会；格式不支持给明确方式；限制与扫描件说明在提交前显示 |
| 会后复盘 | 停止→最后转写收尾→处理/标记未完成项→保存确认→复盘 | 无法保存留在当前会；允许导出救援副本；未完成项可稍后重试，不能伪称完整结束 |
| 找回继续 | 会议库搜索→显示命中类型→打开到对应页/句→继续原会或用旧板新建 | 后者不改原会；加载失败不显示成全新空会；缺素材时保留文字并说明缺少哪些页 |

## 3. 布局与响应式规范

尺寸单位为 CSS px；这是一组设计约束，最终以系统文字/缩放后的可用空间而非固定屏幕型号判断。图见 [wireframes.html](wireframes.html)。原生窗口框、交通灯、系统菜单由平台负责，网页不仿造。

| 区域 | 1280×800 正常桌面 | 720×480 最小窗口 / 较大文字 |
| --- | --- | --- |
| 顶部 | 56 高：会议库/标题/保存状态；右侧复盘、导出、设置；次要动作进入有文字的更多菜单 | 两行约 88 高；标题保留一行，完整名可聚焦查看；导出/设置放更多，但未保存状态常驻 |
| 页导航 | 80 宽页缩略条，可折叠，当前页有文字页号与选中轮廓 | 收为“第 3/8 页”按钮，打开可键盘操作页列表；新页动作在列表末尾 |
| 白板 | 中间可伸缩，选中工具条限制在实际可用画布内 | 占据主要内容区；工具条按实际测量换到可见侧，空间不足进更多菜单 |
| 原话/摘要 | 右侧 320 宽，允许在 280–400 范围调整；原话/摘要/内容列表用 tabs | 与白板在内容区切换（保留页、滚动、焦点）；不在 720 宽硬塞三个栏 |
| 输入/收音 | 底部约 88 高占布局流，不悬盖画布；主收音按钮、来源、字幕/输入分层 | 保留停止/开始及来源；输入展开可滚动，不把停止挤出屏幕；状态详情可展开 |
| 状态与错误 | 保存错误在标题下全宽、持续；局部错误贴近对应任务；非阻断成功通知短暂 | 错误可换行，必要时内容区独立滚动；关闭/重试按钮不离屏 |

超过约 1100 宽可同时显示页栏与侧栏；900–1099 默认折页栏；低于约 900 使用单主区+tab。断点可因字体测量调整，验收以主要操作始终可达为准。200% 浏览器缩放用同一紧凑布局，控件跟文字增高；禁止固定高度+隐藏溢出裁掉正文。画布自身允许平移/缩放，应用外壳不产生水平滚动。

中文/英文及长标题：标签不全大写、不靠小字压缩；主要按钮不省略；正文自然换行，URL/错误堆栈有折行和详情；列表标题最多两行且可打开完整内容。导出名不直接使用未经处理的标题作为路径。手写中文/英文粗细仍独立，日文保留字体与字形回退路径。

## 5. 每个页面与组件的行为

### 5.1 会议库与准备

会议库有持久搜索、最近列表、清楚新建按钮。行内显示标题、时间、页数/原话数、未保存或不完整标记；详情动作“打开、回放、导出、用旧板开始、重命名、删除”。删除先说明标题和后果，成功后更新列表；失败保留确认上下文可重试。空列表、搜索无结果、加载、读取失败是四种不同文案。搜索等待期间保留旧列表但标“正在查找…”，结果绑定查询代次，过期响应不能覆盖新查询。

准备页采用小型就绪清单而非模型目录：音源→转写→板书。每项可展开详情。开始收音必须有实际转写能力；未下载板书模型也可“先记录原话”，说明“白板尚不可用，原话仍会保存”。“检查输入”由用户显式触发短时间电平预览，并明确正在使用麦克风，关闭即停止；不会在开屏或预加载时隐式采集。选择系统声音才解释/申请对应权限。

### 5.2 会中工作区

标题区回答当前会与保存结果，底部回答收音，原话区回答识别，白板区回答生成。状态尽量就近，避免一个绿色“模型连接”被当成“全部正常”。底部收音按钮带文字，启动中可取消，停止中防重复；来源菜单显示所选设备及路由，不把“设备已选”当作“收到信号”。当前后端没有分路电平时写“暂无分路读数”，等待 #71 实现真实计量。

原话侧栏默认跟随新句；用户向上滚动后保持位置，并出现“有 3 条新记录 / 回到最新”。临时字幕与定稿视觉区分，定稿一次入库；修订保留 rawText 和修订关系。每句可显示“待生成/生成中/生成失败/已绘制”，延迟数据在详情中，正常阅读不堆毫秒。真实模型标签只在有意义时显示；本会远程使用持续标明目标主机。

手动说话人仍支持点击切换和 `@名字`；新用户从输入旁菜单发现姓名管理。改名/合并先预览影响，来源不是身份，Apple 当前人工说话人不伪装自动识别。名称合并需同步原话、板书溯源、历史和摘要待重新确认状态。

### 5.3 白板、自由编辑、材料与分页

手绘模式保留节点/边编辑、圈/下划线/高亮/星标/划掉、拖动、撤销、美化、术语与发言溯源。图标工具分成“选择/圈着说”“撤销/重做”“整理布局”三个组。工具条按实测宽高、侧栏和输入区边界定位；不足时优先保留改名与更多，不隐藏危险动作名称；边缘、长英文和200%缩放必须能操作。

圈选有文字状态“已圈住 3 个对象，下一句话将引用它们”，提供取消和撤销一圈；0个对象明确说明，不把空圈当成功；超过8个按既有规则限制并提示。模型排队时每句保留自己的目标，发出后不把新圈套到旧句。

页导航显示当前页/总页和来源文件页码；新增空页不封锁整场导出。用户回看旧页时停止自动跳页，语音翻页或建议翻页需有可解释反馈。继续旧板显示“来自某会第 N 页”，原内容淡墨但仍满足对比度，新增改动以正常墨迹区分，不能只靠透明度传达归属。

提供“内容列表”作为画布语义替代：按页显示节点、连线关系、原文与引用；键盘可选择、定位、改名/删除可编辑项。自由对象至少有类型与用户可编辑名称；没有语义的任意笔迹明确标“手绘笔迹”，不生成未验证的内容描述。该列表复用 graph/场景对象数据，不另建知识结构。

### 5.4 复盘、摘要和回放

复盘显示“原话 N 条 · 白板 N 页 · 尚有 N 项未完成”，摘要是可编辑草稿；结论/决定/任务/待讨论保留来源入口，模糊责任人用“未确认”而非自动确定。#68 的事实性回归是单独门槛，不能靠更漂亮的摘要卡片宣称修复。

摘要生成显示进度阶段，取消保留上一版，重新生成前不会清空人工编辑；已有改动时提供“替换当前摘要/保留当前摘要”，不新增复杂版本管理系统。基于快照的内容变化后提示“会议有新内容，可重新生成”。复制 Markdown/纯文本成功给短反馈；失败给选择文本的退路。清除提供确认或可撤销恢复。

回放独立模式有明确横条：当前位置、播放/暂停、速度、退出、从此分支；不复用收音状态。第0步分支禁用并解释。首末步、拖动后当前页/原话一致；退出恢复进入前工作状态；回放中不自动保存历史画面。分支创建新的页/会按当前已有产品语义显示清楚，原会不被覆盖。

### 5.5 设置、模型与隐私

使用六分类左侧列表，窄窗顶部分类选择；每页独立滚动，离开返回保留合理位置。语言/外观等即时保存，远程连接明确“测试”“保存并启用”两个动作；退出未保存远程表单时保留草稿或提示，不把已测试误当已启用。

模型按用途分组：转写、白板、图片理解。每项用“用途→当前状态→下一步”，文件名/量化/来源/硬件在详情。下载字节总量未知时不造百分比；暂停、恢复、校验、空间不足、损坏、加载失败各有真实文案。推荐只依据实际硬件兼容/已知资源要求，不伪造速度/智能评分。删除当前使用模型明确停用影响，可取消；同时影响的视觉组件显示关联关系。

Apple 面板以能力检测结果为准：检测中/不支持（具体原因）/资源未准备/准备中/已准备/使用中/失败；仅使用现有正式状态枚举，测试 fixture 与生产协议对齐。Auto 写明“开场识别一次语种”，显示实际选中语言；停止收音后才能切换。没有能力/资源时提供 SenseVoice 返回路径；共享 Apple 资源不提供伪“删除模型”动作。

远程页展示真实主机、发送原话/板书上下文的范围，图像能力按实际路径说明。新地址/发送范围变化要重新同意，取消不得发送会议内容。保留每场会仅本地、Key留空沿用、远程失败回本地且明确标识；原始 key 不进入页面日志、诊断和截图。测试连接只发固定探测内容。浏览器连接错误区分 CORS/网络可观测信息，不凭空猜原因。

### 5.6 维护、诊断、更新

维护页保留诊断预览/ZIP/取消/失败重试、纠错评测与偏好数据导出，均用用户任务说明；技术 JSON 默认折叠。诊断在导出前清楚列出包含与排除内容，复用现有脱敏函数；不能把普通失败上报成全量会议内容。

更新提示非阻断；版本说明可读，保持“稍后”。下载更新时可返回会议；下载并校验后，由用户明确选择“保存并重启”。正在收音时先停止收尾、flush保存成功再安装，最终安装前重新检查dirty revision。错误区分检查/下载/签名/安装；失败后按钮与实际状态一致（#77），签名失败不可跳过。重启/安装失败之后，恢复模型与采集状态要明确，不能只调用 llmEnsure 就显示“会议已恢复”。不支持应用内更新的平台显示下载入口。

## 6. 四条独立状态链与错误恢复

以下是界面状态合同，优先将现有状态整理为显式 TypeScript union/枚举，复用现有 IPC，不引入状态机依赖。统一事件携带当前 meeting/page/capture 的归属，后台旧事件不改变新视图。

| 链路 | 状态与主要转换 | 用户可见文案/动作 |
| --- | --- | --- |
| 采集 | idle→requesting/starting→listening→stopping→idle；任一步可error；starting可cancel | “开始收音”“正在启动 · 取消”“正在收音 · 停止”“正在收尾…”；错误指明音源，给重试/重选/打开系统设置 |
| 转写 | unavailable/ready→waiting/speech/partial→finalizing→ready；可以error | “转写未准备”“等待说话”“临时字幕”“正在确认最后一句”；无声≠失败；失败保留已定稿文本 |
| 板书 | unavailable/idle→queued→generating→applied/no-change；可failed/cancelled | “白板未准备 · 设置模型”“还有3句待处理”“正在整理这句话”“这句无需修改白板”“未生成 · 重试” |
| 保存 | clean→dirty→saving(revision)→saved(revision)；可failed | “有未保存更改”“正在保存…”“已保存 15:42”“保存失败 · 重试 / 导出副本”；只有当前revision确认落盘才显示已保存 |

“停止”结束采集输入，并按真实 backend finalize能力等待尾句；最终超时明确说明已保存到哪条、哪些未完成，而不是无期限 spinner。板书仍在生成时允许浏览已完成数据，显示队列；结束会议可选择等待完成或保留待处理项后复盘，后者不会把它们标为成功。

| 情况 | 文案示例 | 恢复与数据规则 |
| --- | --- | --- |
| 麦克风权限拒绝 | “无法使用麦克风。请在系统设置允许 boardcast 访问麦克风。” | 打开对应设置/重新检查；保留系统声状态，不静默改来源 |
| 系统声权限拒绝 | “系统声音尚未授权。麦克风设置不受此权限控制。” | 指向屏幕与系统音频权限；若只启用麦克风需用户明确选择 |
| 有设备无信号 | “已连接麦克风，暂未检测到声音。” | 检查设备/重选，不宣称转写完成；持续阈值须真机校准 |
| 板书模型失败 | “这句话已记录，白板生成失败。” | 原话旁重试/错误详情；按句ID去重应用结果 |
| 网络不可用 | “远程模型暂不可用。已保留原话。” | 有已就绪本地时明确回退；否则排队/重试，不阻止导出 |
| 保存失败 | “最新更改尚未保存，请先重试或导出副本。” | 阻止静默新会/切会/更新；保留当前内存，导出失败同样保留 |
| PDF取消 | “已取消导入，当前会议未变更。” | 仅提交前取消；已提交的导入可走明确撤销批次 |
| 缺失附件 | “2页材料图片无法读取；文字和批注仍在。” | 列缺失页，尝试重新关联/导出可用内容，不改写原文件为无图版本 |
| 更新下载失败 | “更新未下载完成，当前版本继续可用。” | 重新准备/下载，保持原更新版本或说明版本变动；不会直接第二次取空Pending |

本地/远程/语种等状态标签必须依据实际选中和运行结果；定稿计时、分路电平、队列深度在没有测量时显示未知，不补0。“已保存”不是“内容正确”，“正在收音”不是“本机保存了音频文件”。

## 7. 导入和导出的完整合同

### 7.1 导入

复用现有 PDF/图片/arXiv/Excalidraw 处理器，只统一任务外壳：选择→验证→处理中→待提交→提交成功/失败/取消。每个任务固定目标 meetingId/pageId/generation；当前会变化时取消或要求重新选择目标，不能把旧任务结果落进新会。已有 AbortController 能中断的真正中断，不支持中断的处理器也必须忽略取消后的结果并释放临时资源。

提交前展示文件名、将新增页数、40页限制、无文字层/跳过参考页等实际结果。扫描件“显示底图，无自动OCR”；图片缺视觉组件就近给准备入口，不把会议自动发云端。Excalidraw 导入展示可编辑对象数量，保留受支持的原始图形、图片、样式和 customData，并将可表达的对象关联到会议结构；每对节点的额外箭头保留为自由对象。导出包含恢复会议结构所需信息，不宣称任意外部绘图的 JSON 字节一致。错误文件不覆盖当前会；取消后同一文件可重选。

### 7.2 导出

导出面板先选择“整场会议 / 当前白板”，按用途列格式；每个格式独立判断内容能力。只要有原话、摘要、任何一页图/底图/自由对象，即可进入导出面板；真正空格式给禁用原因。生成前固定一份不可变快照，包含页、scene、布局、原话、摘要、时间、笔迹与素材；异步加载导出器期间切页不改变这份快照。

| 格式 | 范围/内容 | 必须验证的产物 |
| --- | --- | --- |
| Markdown | 整场原话/摘要/语义板书；纯转写可用 | 中日英、特殊字符、Mermaid、每页；自由笔迹不可文本化时明确列出遗漏类别并建议视觉格式，不能默默称完整 |
| PNG | 当前板完整视觉（含底图/自由对象） | 边界、不截断、主题、最大像素限制；大图失败给SVG退路 |
| SVG | 当前板矢量/必要内嵌素材 | 离线打开无缺字/底图；必要无障碍标题；自由对象与手绘标记保留 |
| Animated SVG | 当前板按步骤呈现最终视觉 | #53顺序、终态、减少动态；静态自由对象也要保留，能力限制事先说明；GIF/WebM仍归既有issue后续 |
| Excalidraw | 当前板可编辑数据 | 自由对象、生成对象ID/映射与附件齐全；导出再开不依赖当前组件API存活 |
| Meeting PDF | 整场各页+摘要+原话 | 有其他页时当前空页不阻断；长记录分页/截断、文字可选择性如实说明 |
| Replay HTML | 整场步骤、原话、摘要与素材 | 新浏览器context离线file打开，多页/自由对象时序、拖动/速率、键盘/大字 |

进度只显示已知阶段（准备素材/生成/等待保存），不发明百分比。原生保存返回null代表取消，无成功toast；成功后显示真实文件名与路径，“打开/在Finder中显示”使用现有Tauri安全路径能力，若尚无命令只补这两项受限命令，不做通用shell执行。浏览器只能确认“已交给浏览器下载”，不能谎称文件已写到某个目录。路径无权限/磁盘满/取消/生成失败有不同下一步。

## 8. 数据模型、异步生命周期与迁移决策

### 8.1 一份会议，明确每类对象的所有权

当前 `Meeting/Page` 保存 graph/layout/steps/underlay，`PencilBoard` 无 onChange，`App` 每次 graph更新重建scene；这导致#73。决定在**现有 Page 上保存可恢复的自由编辑内容**，不是另建一个与会议脱离的编辑器存档。语义对象以graph为准，用户自由图形/样式以持久scene数据为准，映射明确且不互相猜测。

1. `scene.ts` 为每个由graph生成的对象及其子元素分配稳定ID/来源标识（节点、标签、连线、标记）。数据里记录来源，不能仅用看起来相似的文字反推对象。
2. `PencilBoard.onChange` 区分应用自己的updateScene与用户动作。语义对象的改字/删除/位置变化映射到已有 `edit.ts` / layout 操作；按一次交互批次进入统一撤销、纠错和步骤流。程序回写不重复记录历史。
3. 用户新建的任意形状、笔迹、图片以及graph无法表达的样式保存在Page的scene部分，连同必要文件引用；不自动转换为模型语义。模型更新只更新自身拥有且未被用户覆盖的字段；冲突保留用户版本并给明确重新采用生成版本的动作。
4. 切页/切模式前capture当前完整Page；仅有自由对象的页面也算非空并触发保存。重进PC从持久Page恢复，不能再无条件用graph覆写整场scene。PAD可把自由对象作为可定位的视觉层显示，编辑它们时进入自由编辑；必要时复用Excalidraw现有SVG输出，不另造笔迹解析器。最终#9统一笔迹/底图仍要完成，不能用占位丢图宣布完成。
5. 不支持在PAD语义编辑的对象必须保留、可见、可导出，并明确“在自由编辑中修改”；不能以隐藏/删除/禁用PC编辑降低兼容要求。原始场景始终可导出救援。
6. 全局撤销记录graph/layout/scene的一次批次；输入框保留系统文本撤销。复用 `History<T>` 扩展批次内容。`Step` 在现有graph diff之外加可选scene变化，在相同时间线记录，不能每个pointermove存整张会；初始/最终快照与重放结果需round-trip一致。

字段命名在实现PR确定，但P1落地前必须有固定的所有权与冲突测试。不得只加一个“scene JSON”字段却继续让模型重画覆盖用户内容，也不做任意Excalidraw→Graph的有损全量转换。

### 8.2 保存与跨会隔离

复用现有 `meetings.save`、资产哈希与Rust临时文件rename，补**单会议有序写入和revision确认**：相同会议不能多个异步保存互相覆盖，旧revision成功不清新dirty；IndexedDB以事务complete而非单个request success作为提交完成；资产全部成功后再提交引用，失败不把缓存标为已存。

`reset/openOther/continueOn/import commit/update install/close` 走同一个“结束当前操作→捕获→等待save确认→切换”边界，避免每个入口吞异常。新建或切换时若在收音，先让用户选择“停止并切换/留在当前”，停止后收尾并保存。失败留在当前会议，可重试或导出完整副本；用户明确放弃才丢弃，不能默认继续。

模型/摘要/导入任务绑定 meetingId、pageId和一次性generation；取消/切会后旧结果要么应用到明确的旧会存储，要么取消并标待处理。此次选择后者，以现有Session为边界取消，不新增后台任务管理器。迟到的success/error/finally都不能改变新会状态。已接收的原话先保存，取消生成不丢原话，重试按句ID防重复。

### 8.3 版本迁移与回滚

新增scene/步骤后升 `MEETING_VERSION`，提供v1→v2纯转换和未知新版本只读保护。旧文件没有scene时按原graph/layout生成，不能“推断恢复”过去已丢失的PC编辑。迁移是首次实际编辑时copy-on-write，不启动时批量重写用户资料。

为避免旧客户端保存时删掉新字段，v2记录使用现有应用数据下独立`meetings/v2/`命名空间（Web使用独立v2 store，复用同一DB和资产协议），保留v1原件及素材；仅复制被迁移会议实际引用的素材到v2所属目录/键前缀，避免旧客户端删除v1会议时带走v2仍需的素材。列表按ID优先v2，首次迁移全部资源及记录提交成功才登记完成。不要双向同步两个版本。保存源v1的updatedAt/hash，若降级后v1被另改，升级时提示“发现旧版本副本”，让用户作为副本打开，不能静默覆盖v2。

回滚UI批次无需降数据格式；若必须降应用版本，保留v2原件，用户可打开迁移前副本并看到其时间，或先导出当前完整Excalidraw/视觉/记录救援。新数据无法无损降级时明确说明，禁止自动删除v2或声称回滚保留了全部新编辑。使用原有valid_id/asset校验，新的scene引用也不能接受任意路径；导入体积、JSON结构、二进制资源与外链均有边界验证。

迁移门槛：带底图/多页/旧回放/说话人/术语/纠错/摘要的v1 fixture读入不变；仅自由对象也可存；任意一步写入失败原件可读；v2保存重开/导出/回放终态相同；未知版本不写回。并行多实例至少阻止旧revision覆盖或显式提示冲突，不声称支持实时协作。

## 9. macOS、键盘和可访问性

原生App/File/Edit/View/Window/Help菜单映射现有动作；设置支持Cmd+,，标准剪切复制粘贴全选与撤销遵从系统焦点，文件导入/导出用原生选择器。菜单中显示快捷键，但不要预设尚未实现的快捷键已工作；盘点现有 `shortcuts.ts/shell.rs` 后消除与Excalidraw/输入法/系统的冲突。全局收音、托盘与CLI保留，托盘跟随语言；关闭窗口/退出的含义和采集清理在Mac真机验收后固定。

统一Dialog行为：打开时聚焦标题或首个合理控件，背景inert/快捷键停用，Tab/Shift+Tab留在顶层，Escape关闭最顶层可取消操作，关闭恢复触发点。忙碌不能关闭时说明原因；权限/文件选择器交给系统，不再叠自制焦点锁。`/`、`?`、Space、编辑快捷键必须先检查模态/文本输入/IME组合。可从现有ModelPanel提取一个小的共享Dialog壳，不新建配置式弹窗框架。

menu支持方向键、Home/End、Enter、Escape，tab按tablist语义；所有icon-only名称正确，本地化后不丢名称。radio/checkbox/select优先原生语义。动态状态用polite合并播报，严重保存失败用一次明确通知；不播报每帧电平、每笔动画和重复错误。原话区允许停止自动播报，不打断当前阅读。VoiceOver可从会议→状态→画布内容列表→原话→停止按钮完成闭环。
