## 测试发现的实际问题

- 跨会摘要命中先选择摘要，随后默认初始化又切回原话。默认 tab 现在在打开会议时初始化，搜索命中可以随后选择目标。
- 未来版本等错误原先只出现在会议库背后的 toast。转换失败保留具体原因，会议库在自己的 alert 中展示，当前会议与原件保留。
- 回放只拒绝保存编辑，却仍允许自由编辑画布呈现未保存的新对象。现在画布本身切为只读。
- 示例的 `loadedMeeting` 标记没有在进入个人编辑前清除，第一句新内容被误记为已加载基线，未触发自动保存。示例现在没有“已保存”的虚假状态；首次个人输入正常保存。
