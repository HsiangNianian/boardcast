# 内容列表与复盘实施验收

2026-11-03，当前工作树的生产构建，Chromium；对应方案 §5.3、§5.4、§6、§9。未提交、发布或关闭 issue。

侧栏拆为原话、摘要、内容列表三个 tab，支持方向键、Home/End 和保留原话滚动。宽屏侧栏可以在 280–400 像素间调整，窄屏切换白板与会议详情。

内容列表直接读取当前页 graph/scene，显示节点、父项、分组、连线、原文及标注。导入原文只读，已有来源可以跳回原话。自由对象显示实际类型，允许设置名称；名称不改写画面文字，也不自动描述图片或笔迹。语义改名复用既有操作与历史；自由对象删除同时清理其绑定，并纳入统一撤销和持久化。

定位会居中显示目标，窄屏显示白板并在可见状态生效后转移键盘焦点。回放读取该步骤的自由场景，隐藏尚未出现的对象；列表和共同编辑入口均拒绝回放期间的写入。tab 和按钮按键不再被回放快捷键抢走。

“结束并复盘”执行停止收音及尾句收尾、等待板书或显式保留未完成项、保存确认，再进入摘要页。未完成项保留失败/取消状态和逐句重试入口。保存失败保留当前会议及复盘对话框，提供重试与导出副本；不会显示已经完成复盘。继续收音或输入新句会返回工作状态。
