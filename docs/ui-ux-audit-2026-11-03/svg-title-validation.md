# C47 SVG 文档标题与无障碍名称

2026-11-06，基线 `503b677`。手绘、自由编辑和动态 SVG 的实际下载文件都缺少文档标题，Chromium 无障碍树中的整张图名称为空。五种会议标题、三种 SVG 路径的对照检查中，旧版 30 项失败、6 项通过；修复后全部 36 项通过。

## 改动与验证

`src/exporter.ts` 在共同的 SVG 输出处加入会议标题；空标题使用构建开始时语言对应的“未命名会议”。复用平台 XML 解析、文本节点与序列化，避免把标题中的标记当作代码；XML 无法表示的控制字符与未配对代理字符替换为 U+FFFD。只修改导出内容，不修改保存的会议标题。

[SVG 规范](https://www.w3.org/TR/SVG2/struct.html)将直接子级 `title` 用于可访问名称。这里不覆盖自由编辑 SVG 原有的语义角色；实测其内部文字仍出现在无障碍树中。

| 生产 App 实际下载 | 结果 |
| --- | --- |
| 英文标题含 `<&>`、引号、闭合标签、脚本文字、`$&`、日文与 emoji | 三种输出都只有一个直接子级标题，保持原文字面含义，无脚本节点。 |
| 中文换行、日文与 emoji | XML 文本保持；无障碍名称按浏览器规则折叠空白。 |
| 空字符、非法控制字符、未配对代理字符与 U+FFFE | 生成可解析 XML，四处替换为 U+FFFD，合法 emoji 保持。 |
| 英文空标题、中文纯空白标题 | 三种输出分别得到 `Untitled meeting` / `未命名会议`。 |
| 自由编辑文字 | 五份输出的 `EDITABLE_LABEL` 均仍作为可读文字存在。 |

[回归脚本](../../scripts/ui/check-svg-title.cjs)从真实 IndexedDB 会议，经生产界面下载 15 个 SVG，再在独立 Chromium 文档中读取无障碍树；没有模拟导出器或原生读屏。最终入口为 `index-BkjqwVNd.js`。基线、下载文件、无障碍树和日志保存在本地 [证据目录](evidence/implementation/svg-title/)，原始证据未上传。

首次探针在独立 SVG 的整页截图时超时，不能作为完整基线。最终脚本直接保存 SVG 和无障碍树；完整基线已重新执行，图形与动画由既有视觉回归检查。

同一最终生产构建另通过七格式 92 项、动画 30 项、外观 82 项检查；涵盖静态/动态终态、底图、自由对象、实际 PNG/PDF 和离线回放，原会议记录保持。完整 Node/Eval 341 项、TypeScript、播放器和主应用构建通过。1430 预览已更新并逐字节核对 11576 个文件，旧资源和原 1423/1430 进程保留；没有重跑原生测试或安装新包。
